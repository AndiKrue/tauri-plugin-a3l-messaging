# WO-A3L-001 — Tauri 2 A3L Messaging Baseline

## Objective
Create an open-sourceable Tauri 2 plugin surface for Amazon A3L Messaging without product-specific
semantics or redistribution of Amazon's AAR.

## Acceptance
- One Rust command surface for Android/Fire OS and explicit desktop `unsupported`.
- Token retrieval, provider/platform inspection, topic subscribe/unsubscribe.
- A3L receiver handles token/message callbacks.
- Native callback queue is bounded to 100 and atomically drainable.
- JavaScript bridge failures are typed results.
- A3L AAR is Git-ignored and documented as an external prerequisite.
- JS tests pass.
- Android acceptance remains explicitly pending until the AAR/toolchain/real Fire OS gate is run.
